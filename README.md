# FELLAGUE: REALMS

Developed by FELLAGUE STUDIO

## About the Game
An original 3D mobile online strategy game focused on building, developing, and defending a fantasy village.

## Core Vision
- One fixed plot of land.
- Free placement of buildings and walls.
- Camera movement in four directions.
- Village development through upgrades.
- Major visual evolution at Level 10.

## World and Army
- Monster-only army.
- 30 initial monster types across 6 families.
- 4 unlockable fantasy heroes.
- Each hero has a unique companion.
- Army capacity controlled by camp upgrades.

## Development Principles
- Mobile performance first.
- High-quality 3D visuals.
- Original designs and systems.
- Clean project structure.
- No unnecessary features.

## Technology
- Godot 4.7.2
- Android and other supported platforms.
- Compatibility / OpenGL ES 3.2 when needed.
