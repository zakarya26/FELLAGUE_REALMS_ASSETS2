# FELLAGUE: REALMS - Project Structure

## Project
Original 3D online mobile strategy game.

## Main Systems
- Village and building system
- Camera movement system
- Building upgrades
- Resource and storage system
- Monster army system
- Hero and companion system
- Defense and walls system
- Online progression and saving

## World
- One fixed land plot
- Free building placement
- Four-direction camera movement
- Level 10 visual evolution

## Development
- Godot 4.7.2
- Android
- Mobile performance optimization
